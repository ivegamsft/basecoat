# Security Remediation Closure Evidence Template

Use this template to record closure evidence for each security finding.

## Finding metadata

- Finding or issue: `<issue-url-or-id>`
- Severity: `critical|high|medium|low`
- Owner: `@owner`
- Due date: `YYYY-MM-DD`
- Closure type: `fixed|risk_accepted`

## Implementation evidence

- PR(s): `<pr-url(s)>`
- Commit(s): `<sha(s)>`
- Scope summary: `<what changed>`

## Verification evidence

- Scanner/workflow output: `<run-url-or-artifact>`
- Validation command(s): `<command>`
- Result summary: `<pass/fail and notes>`

## Risk acceptance (if closure type is risk_accepted)

- Acceptance record: `<doc-or-issue-link>`
- Expiration date: `YYYY-MM-DD`
- Compensating controls: `<controls>`
- Approver: `@approver`
