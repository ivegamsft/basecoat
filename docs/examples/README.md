# Examples

This directory contains reference implementations and project scaffolds.

## Categories

- **Read-only examples**: small, illustrative samples meant for reference
- **Project scaffolds**: folder structures that can be copied into a new repo

## Current contents

- `iac/` — Azure infrastructure examples
- `repo-template/` — repository scaffold for BaseCoat pinning and enforcement
- `basecoat-memory/` — shared-memory scaffold for org-wide BaseCoat memory

## Guidance

Keep examples focused on real usage patterns. If a sample grows into a full repo starter, keep it here only if the intent is clearly scaffold reuse.
